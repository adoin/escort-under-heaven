# 《紫色晶石 / Stoneshard》玩法拆解

玩家扮演阿尔多（Aldor）的佣兵。格子回合制决定一场冲突怎么打，伤病和经济决定这趟还能走多远。一次成功的出门要把战果带回可补给、可交差的地方，才能转化为下一次冒险的本钱。

## 资料口径

以截至 2026 年 11 月 23 日可查的 Steam 商店、开发者更新和官方站点 Wiki 为依据。已发布机制以 0.9.1.0《Rags to Riches》及 0.9.4 系列《Blood Omens》等版本为参照。《Ancient Echoes》的任务扩充按开发预告处理。失败段落均为机制推演，未核实的固定数值或触发条件标为「待验证」。[Steam 商店][steam] · [开发者公告][news] · [Rags to Riches 开发者更新][rags] · [Blood Omens 更新][blood] · [任务开发日志][echoes]

## 01｜核心循环

**它是什么**　城里接活、买补给和修装备 → 按路线出门 → 在野外或地牢交战、取目标和战利品 → 判断该深入还是撤离 → 回城交差、出售战利品、治疗、睡觉 → 用净收益换成长与下一次出行能力。长期并行目标是推进韦伦（Verren）的晶石调查、扩大商队活动范围，以及练出能承担更高风险委托的角色。[Steam 商店][steam] · [契约与主线][contracts] · [商队][caravan]

**为什么好玩**　出门时的投资会变成现场的选择。背包里最后一格既可以装备用药，也可以留给值钱的战利品。拿到任务物后，玩家仍要根据伤势、路程和剩余补给决定是否多探一间房。

| 关键数值或规则举例 | 对决策的影响 |
| --- | --- |
| 契约可以谈报酬和交付时限，实际条件以契约为准。[契约][contracts] | 出发前就要决定能不能承担往返和绕路。 |
| 物品占用网格背包空间，移动商队提供额外后勤。[物品][items] · [商队][caravan] | 判断战利品时同时考虑占格和变现，进阶后可改变出发与回收路线。 |

**失败体验**　取到目标后又去搜房，挨了一次伤，原本能支撑返程的药用光。即使战斗打赢，回城也可能亏钱，甚至死在返程。

**可借鉴点**　让交差、治疗、整备自然衔接。结算可显示报酬和实际支出，让玩家知道该提升战力、压缩路线还是提前撤退。

## 02｜开放世界结构

**它是什么**　阿尔多是世界舞台，当前冒险地图由地区和连续的本地地图格构成。城镇、村落和商队营地供交易、休息、接活，林地与道路承担通行和野外遭遇，要塞、墓穴、地下墓窟等属于地下城或地牢玩法的一组地点。中文「地下城」和「地牢」在此统称此类据点，内部可分房、走廊和楼层；远郊地牢给高风险探索独立目的地。[世界地图][map] · [地下城][dungeons] · [商队][caravan]

**为什么好玩**　城镇是回收节点，地牢是风险节点，野外连接两者。路线的价值取决于路程、附近补给、敌人分布和未知地点。契约告诉玩家该往哪里去，路边遗址、传闻或岔路又提供偏航理由。

| 关键数值或规则举例 | 对决策的影响 |
| --- | --- |
| 全局地图按地块组织，选定路线后在本地地图通行。[世界地图][map] | 可以用路网规划整趟行动，再在局部绕开遭遇。 |
| 有契约关联地点，也有远郊探索地点；敌人、生态和房间组合因地牢类型而异。[地下城][dungeons] | 同一条出行路线可以为了交差，也可以为了挑战或寻宝。 |

**失败体验**　发现一处远郊遗址便立刻进去，半途受伤才意识到离下一个休息点太远。地图越大，缺乏可辨认的风险和路标时，越容易只剩赶路。

**可借鉴点**　先让一片小区域具备主路、捷径、危险支路和明确的回程地标。区分地表发现地点与进入实例，后者要让玩家察觉风险提高。

## 03｜格子回合制战斗

**它是什么**　探索和战斗共用格子与行动时钟。玩家执行耗时行动后，有行动机会的敌人和环境推进；多敌压力来自一次玩家行动可能换来多个敌方响应。眩晕、定身等状态按各自规则改变可选动作。敌方同一轮内的精确排序、个别动作与状态结算的先后待逐版实测。[Steam 商店][steam] · [战斗规则][combat] · [状态效果][effects]

**为什么好玩**　走一格也在花战斗资源。利用门洞隔开两名敌人、等敌人自己进入射程，或先退到能喝药的位置，往往比多打一刀更有效。

| 关键数值或规则举例 | 对决策的影响 |
| --- | --- |
| 常规走一格、普攻、等待、使用多数战斗物品等会推进一拍。查看信息与实际执行是两件事。特殊物品或技能按各自说明。[战斗规则][combat] · [物品][items] | 喝药或换位要预留安全距离，打开界面可以先判断。 |
| 切换预设武器组通常费一拍。习得 `Dexterity` 后，从远程武器组切至近战武器组可免一拍。背包换装、装填及各技能单独核对。[Dexterity][dexterity] · [战斗规则][combat] | 副武器能覆盖弱点，但临敌切换有窗口成本。 |
| 近战看相邻格和技能范围。冲锋、远程及法术按各自格数、路径和目标限制，距离用技能提示核对。[战斗规则][combat] · [技能树][skills] | 可以在敌人的有效距离外准备，但不能用自己的普攻距离估算敌招。 |
| 墙体和门洞约束移动和视线。0.9.4 光照开发日志给出的示例是暮光使视野范围减少 30%，黑暗中减幅达 60%。噪声能引起敌人警觉。[光照开发日志][light] · [噪声与隐匿][noise] | 看不到敌人仍可能引起注意，关门、光源和视线交角都会改变接敌。 |
| 相对站位决定攻击、冲锋和射击路径。未察觉的敌人可成为潜行背刺目标，通用正侧背倍率以及单靠绕到背后是否触发待实测。[噪声与隐匿][noise] · [战斗规则][combat] | 优先验证射线、障碍与跑位，朝向加成可作为独立规则评估。 |

**失败体验**　玩家在一击距离内换武器，旁边第二名敌人也获得响应。明明只做了一个操作，近战和远程威胁却一起结算。

**可借鉴点**　预览行动耗时、射程、遮挡与已知威胁格。把敌方动作来源和关键状态变化写进短战报，让玩家能找出失败发生在哪一拍。

## 04｜角色成长与无职业构筑

**它是什么**　起始角色有属性、天赋、装备和可用技能树差异。升级可分配属性点和能力点，战技可沿武器、战斗通用或法术等树发展，部分能力需要前置能力和相应的解锁条件。角色可以随着训练与资源改走混合路线，装备、属性和技能共同定义实际打法。[Steam 商店][steam] · [角色][characters] · [属性][attributes] · [能力点][ability] · [技能树][skills]

**为什么好玩**　先按战术问题选能力，再形成职业感。爱控距离的人可以走长柄加辅助能力，爱贴身压制的人可以走盾与近战。起始差异让同一目标有不同成长路径，有限点数、武器要求、装备取舍又使每次投资都有机会成本。

| 关键数值或规则举例 | 对决策的影响 |
| --- | --- |
| Steam 宣传超过 200 种能力、超过 400 件装备。数字是内容规模口径。[Steam 商店][steam] | 构筑的组合入口来自能力与装备的相互作用，实际可用组合受装备和解锁约束。 |
| 基础属性有力量、敏捷、感知、活力、意志。Wiki 所列常规升级奖励为 1 属性点和 1 能力点。[属性][attributes] · [属性点][stat] · [能力点][ability] | 属性点改变派生能力，能力点投资具体打法，两条成长线可以互相配合。 |
| 读专精书、找训练师及部分能力的属性门槛参与解锁。能力点用来实际习得技能，武器技常要求持对应武器。[能力点][ability] · [技能树][skills] | 能解锁、能学习、当前能施展是三个不同检查点。 |

**失败体验**　为了多试几种武器，把早期点数分散到多个入门攻击，结果没有止损的位移或防御能力。换到不匹配的武器后，已学的部分招式也用不上。

**可借鉴点**　先做少量互通的树，让每条主修早期拥有清楚的战术循环；开局预设降低选择压力，装备提示清楚标出招式需求和下一个可学节点。

## 05｜生存、伤病与治疗

**它是什么**　生命和部位状况分层，饥饿、口渴、疼痛、疲劳及精神指标又改变后续的出行与作战能力。挨打先成为当下的掉血与伤势，随后变成撤离难度、治疗回合和补给成本。清完房间后，伤病仍会影响返程。[伤势][injuries] · [生命][health] · [生存及精神指标][survival] · [状态效果][effects]

**为什么好玩**　「止血」「处理部位」「恢复生命」「压住疼痛」通常是不同的事。玩家要判定最紧迫的问题，并判断眼前的安全窗口够不够处理它。

| 关键数值或规则举例 | 游戏内处理与影响 |
| --- | --- |
| 生命与身体部位状况分别记录。伤势跨阈值会限制生命上限，并按部位与严重程度产生惩罚。[生命][health] · [伤势][injuries] | 恢复生命、处理伤势与休息各有用途；腿、臂、头伤会改变移动或战斗表现。 |
| 流血是持续失血。Wiki 所列普通绑带各处理一处流血。多处流血要逐处处理，且还可能有部位损伤。[绑带][bandage] · [状态效果][effects] | 身上带药也要先争取一拍，靠反复回复生命容易被持续失血压回去。 |
| 骨折按严重部位伤理解。夹板用于受伤部位，具体恢复依当前物品说明。[夹板][splint] · [伤势][injuries] | 绑带解决流血，夹板针对部位伤，相同攻击可以造成两种后果。 |
| 疼痛累积会触发惩罚。酒精可作临时止痛，部分止痛药也能压痛，代价随物品变化，酒精还可能导致醉酒或宿醉。[疼痛][pain] · [状态效果][effects] · [物品][items] | 止痛能支持脱离战斗或走路，之后仍要处理伤势。 |
| 中毒、食物中毒状态与全局的 `Intoxication` 有关联。解毒剂可解除 `Poisoning`。放血针在游戏中降低 `Intoxication`，代价包括增加疼痛、降低部位状况和流血抗性。[毒素指标][intoxication] · [放血针][lancet] · [药品][medicine] | 根据状态选择即时解毒或处理毒素积累，避免在伤势已经失控时增加负担。 |
| 饥饿与口渴跨状态阈值后影响续航；食物和饮水要分别处理，休息可应对疲劳。[生存及精神指标][survival] · [状态效果][effects] | 水、食物、药和战利品共享携带预算。 |
| 士气、理智有各自的触发条件，会关联不同精神效果。0.9.3 重做后两者各细分为三个组成项。休息与特定食物或消耗品的影响按条目判断。[精神系统][psyche] · [状态效果][effects] | 精神是长段出行中的累积反馈，状态提示要说明来源。 |
| 官方 Wiki 将独立疾病系统 `Maladies` 列为尚未实装。已有 `Immunity` 指标及食物中毒等状态，按各自说明处理。[免疫][immunity] · [疾病][maladies] · [状态效果][effects] | 食物中毒可以形成独立决策，疾病谱和感染机制属于可另行设计的内容。 |

**失败体验**　以教程《序章》为例，新手受到流血后可能把剩余生命当作足够还能砍几刀，仍选择攻击或移动，每次行动都给流血更多结算机会，最后没来得及绑扎便倒下。这是规则推演；教程哪一战触发、累计几拍致死取决于战况，固定触发点待实测。[序章商店页][prologue] · [绑带][bandage] · [状态效果][effects]

**可借鉴点**　保留「即时危险、后续损伤、资源损耗」三层因果。先教玩家辨别危险来源，再通过短提示给出治疗目标和行动成本。

## 06｜经济、商队与后勤

**它是什么**　收入来自契约、出售战利品和区域间交易，支出覆盖药食、住宿、耐久修理、武器护具及后期商队投入。不同商人、地区商品供给及聚落状况产生差价。移动商队提供营地、运输、仓储、改装和随从专长，强化的是连续几趟的后勤能力。[Rags to Riches 开发者更新][rags] · [契约][contracts] · [商队][caravan] · [聚落状况][situations]

**为什么好玩**　一次胜利有毛利和净利之分。药食、磨损和绕路会吃掉奖金，而商队升级能降低后续远征的折返成本。卖什么、在哪里卖、带什么走因此都能成为路线选择。

| 关键数值或规则举例 | 对决策的影响 |
| --- | --- |
| 不同商人对商品有不同估价偏好，聚落状况可影响物价或货源。实际利润要看交易价和运输条件。[Rags to Riches 开发者更新][rags] · [聚落状况][situations] | 跑商要比较买价、卖价、占格、路费、时间和风险。 |
| 契约可以协商报酬等条件，商队则受出行资源、升级和营地位置等约束。[契约][contracts] · [商队][caravan] | 小额稳定任务能供给长期升级，长途订单要把折返算进去。 |
| 随从可以为商队提供专门服务或加成，具体能力以人物为准。[Rags to Riches 开发者更新][rags] · [商队][caravan] | 招募是在扩充补给与经营选项，前线战术仍以主角为中心。 |

**失败体验**　花光现钱更新兵器，出门后才发现缺水和修甲钱。或者把背包装满高标价商品，却在目的地卖不上价，还挤掉了药和任务物品的位置。

**可借鉴点**　做出低成本保底和可计算的高风险投资。先保证战利品、补给和维修三个价格锚点，再扩展商路和商队设施。

## 07｜探索、主线与任务

**它是什么**　主线围绕韦伦与紫色晶石引出的调查。已发布的内容包含组建商队和到布林（Brynn）调查格温内尔（Gwynnel）的线索。契约给可执行的短期委托，城镇差事、野外遭遇、遗址和藏宝提供路上的偏航目标。《Ancient Echoes》预告扩充 `Tasks`。更广泛的随机事件系统另见路线图。[契约与主线][contracts] · [任务开发日志][echoes] · [开发路线图][roadmap] · [世界地图][map]

**为什么好玩**　同一趟行动可以同时服务三件事。契约给钱，途中发现给新路线，线索让玩家决定下一站。目标有远近之分，某趟失败仍可能学到新路线或记住危险位置。

| 关键数值或规则举例 | 对决策的影响 |
| --- | --- |
| 契约目标可包含回收物件、击杀目标等，交付和期限按任务变化。[契约][contracts] | 先明确完成判定，拿到目标后可以主动撤回。 |
| 野外有既定地点和当前可遇到的随机强盗伏击。地点与随机刷新的敌人各有规则，完整的随机事件库以路线图为准。[世界地图][map] · [随机遭遇][encounters] · [开发路线图][roadmap] | 熟悉地标能帮助估算路程，变动遭遇保留临场风险。 |
| 任务、探索点和宝藏线索可以并行激励。传闻可指向遗址或宝物，主线完结方式待后续内容验证。[传闻与遗物开发日志][rumors] · [契约与主线][contracts] | 长短目标可共存，玩家能在主动回城与临时绕路之间选择。 |

**失败体验**　为了追一条藏宝传闻离开约定路线，回来时契约过期。若任务日志只写区域且没有地标、方向或时限，探索会变成无目的扫图。

**可借鉴点**　每次主线推进给一个可执行下一步。契约列出危险、地点、交付对象与时限，自由探索至少给一个可读地标和一个潜在收获。

## 08｜存档与死亡惩罚

**它是什么**　旅店、已配置床位的商队营地和某些探索地点可通过睡眠建立可回读存档。携带铺盖可在符合条件的野外建一次性睡眠点。退出存档用于恢复会话。铁人选项把角色死亡变为永久损失。[睡眠与存档][sleep] · [铺盖][bedroll] · [退出存档开发者公告][save] · [Steam 商店][steam]

**为什么好玩**　安全点不是恒定跟随的资源。玩家从床位离开后要对这一趟的选择负责，回到城镇或找到营地会切实改变心理预期。

| 关键数值或规则举例 | 对决策的影响 |
| --- | --- |
| 普通死亡回到上一个可用存档，之后的路程、成长、任务进度和所得战利品随回档丢失。[睡眠][sleep] · [退出存档开发者公告][save] | 一旦收益已经足够，撤回安全点有实际价值。 |
| 退出存档用于续玩，开发者说明加载后删除。床铺存档提供死亡后可回读的基准。[退出存档开发者公告][save] | 中断生活会话与战斗失败是两种不同的损失。 |
| `Permadeath` 下死亡结束该角色的进度。便携铺盖、野营点可用条件以版本实际为准。[Steam 商店][steam] · [睡眠][sleep] · [物品][items] | 加重单局承诺，适合已了解风险的玩家主动选择。 |

**失败体验**　连续完成多件事却未记录检查点，最后在回城前死去。玩家丢失的时间过长时，死亡的主要感受会从战术教训变成重复劳动。

**可借鉴点**　把可回读检查点、会话续玩和永久死亡设计成三种清楚的规则。明确告知上次记录的位置、回退后果和下一处可能安全点。

## 09｜难度与硬核设计

**它是什么**　游戏提供可玩的《序章》教程，正式冒险让玩家自行使用提示、检查敌人与装备，判断交战、补给和撤退。难度来自风险叠加，尤其是连战负担、药耗、地形误判与回程。[序章商店页][prologue] · [Steam 商店][steam] · [战斗规则][combat]

**为什么好玩**　有效学习会改变下一次的行动。同样的两名敌人，先检查威胁范围、让一名敌人跨过门洞，再用有准备的反击就可能得到完全不同的结果。连锁失败和由此学到的解法让重复有价值。

| 关键数值或规则举例 | 对决策的影响 |
| --- | --- |
| 药品、换位与出招共享行动机会，受伤后攻防表现可能下降。[战斗规则][combat] · [伤势][injuries] | 准备要落实到进门站位、携带物和撤退方向。 |
| 一次失败可同时影响生命、装备磨损、药耗和存档进度。[物品][items] · [伤势][injuries] · [睡眠][sleep] | 胜负是多次小决定的合成，选择撤退也可能是成功止损。 |

**失败体验**　初见强敌时，玩家不知道危险范围，才靠近就被控制，然后在惊慌中连点多走几格。如果界面也说不清谁上了状态，死亡便难以复盘。

**可借鉴点**　保留可预测的严重后果，前置危险提示与首次安全演练。用短回合战报呈现关键因果，允许玩家一步步执行和撤退。

## 10｜像素美术、音效与氛围

**它是什么**　用像素地形、人物和装备轮廓表现低魔中世纪；聚落、林地和昏暗地牢通过明暗、材质、动效及声音形成不同的安全感。商店预告可观察这些呈现，光照参与视野与潜行属于开发者明确描述的规则。[Steam 商店与预告][steam] · [光照与潜行开发日志][light]

**为什么好玩**　室外的开阔、地牢的遮挡和城镇的安定共同给路线赋予情绪。近战碰撞与动作反馈让一次负伤有触感，环境声和突然安静提醒玩家观察，破损感和补给窘迫把自己放回佣兵处境。

| 关键数值或规则举例 | 对决策的影响 |
| --- | --- |
| 格子、人物轮廓、门洞和光源提前交代局部空间；实际视界按光照、遮挡与单位状态处理。[Steam 商店与预告][steam] · [光照与潜行开发日志][light] | 美术让玩家先读出能否通行和哪里可能藏敌，再查精确提示。 |
| 环境、交击与受伤反馈可从官方展示观察；音效混音、触发概率与听距数值待验证。AI 感知应以规则资料为准。[Steam 商店与预告][steam] · [光照与潜行开发日志][light] | 区分玩家听见的表现音和用于 AI 警觉的游戏事件。 |

**失败体验**　暗色敌人、地板与危险提示挤在同一个明度区间，玩家看不见可走位置。移动端静音时，靠声音单独传达的重伤也会丢失。

**可借鉴点**　把可交互门、出入口和危险轮廓纳入像素规范。用颜色、形状、短动效与声音同时表达高危事件，静音时照样能判断下一拍。
